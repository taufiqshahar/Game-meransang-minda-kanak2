# Prototaip (arkib)

Folder ini ialah **arkib** prototaip awal, satu fail HTML setiap game. Mulai v0.5, sumber utama produk ialah **`app/`**: satu app dengan modul kongsi, satu laman utama, satu zon ibu bapa dan satu had masa harian untuk semua game.

Jangan kemas kini game di sini. Ubah `app/games/<id>/index.js` sahaja.

| Prototaip | Dalam app |
|---|---|
| `lampu-isyarat-haiwan/` (v0.4) | `app/games/lampu-isyarat/` |
| `sorok-sorok-hutan/` (v0.2) | `app/games/sorok-sorok/` |
| `rumah-haiwan/` (v0.1) | `app/games/rumah-haiwan/` |
